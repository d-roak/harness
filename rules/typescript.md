# TypeScript

## Toolchain
- pnpm. Never npm or yarn. Lockfile committed.
- `"strict": true`. ESM. `moduleResolution: bundler` for apps.
- Vite for SPAs and libraries. Next.js only when SSR is a hard requirement.
- Vitest, `@testing-library/react`, `userEvent` over `fireEvent`.
- Prettier (tabs, no semi, width 120) and ESLint flat config.
- Turbo for monorepos. Workspace packages referenced by `workspace:*`.

## Types
- `interface` for object shapes, `type` for unions and utilities.
- `unknown` then narrow, never `any`. `as const` for literal inference.
- Discriminated unions for variants. Exhaustive `switch` with a `never` default.
- zod at boundaries; infer TS types from the schema, not the other way round.

## Patterns
- Named exports. No default exports except where a framework demands one (Next pages, Vite config).
- Minimal barrel files. Re-export public API only.
- `async/await`, optional chaining, `??`. `Map`/`Set` when keys are dynamic.
- Errors: throw typed errors at the boundary; a `Result`-style return inside hot paths if it reads better. Pick one per module.

## React
- Functional components, hooks, named exports.
- Server state via TanStack Query. Local state via `useState`; reach for a store only when three or more unrelated components share it.
- Tailwind with tokens from `tailwind.config`. shadcn/ui components copied in, not wrapped.
- `@phosphor-icons/react`. No other icon library.
- Accessibility basics are not optional: labels, focus order, keyboard paths, contrast.

## Backend
- Hono for HTTP. Drizzle over Postgres. Better Auth for sessions.
- BullMQ + Redis for jobs. One queue per job type, idempotent handlers.
- Migrations checked in, generated by Drizzle, never edited by hand after they run.
