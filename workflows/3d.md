# 3D asset or render

```
plan → blender (scene → materials → light → camera) → render or export → review
```

1. Plan in the reply: subject, purpose (hero still, turntable, web GLB), dimensions, aspect, the still bible or `DESIGN.md` it must match.
2. `blender`: fresh file, named objects, real scale, Poly Haven materials and HDRI, AgX, EEVEE while iterating with viewport captures.
3. Final: Cycles with fixed samples and denoise for a still, or GLB with draco for the web. State the settings and the file size.
4. `review` against the plan side by side: framing, light direction, palette. Named differences or a regenerate.
5. Hand the render to `imagegen` as a reference, or to `videogen` as a shot, or to `implement` as an asset.
