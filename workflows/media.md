# Media set

```
copy → imagegen (bible + stills) → videogen (clips) → review → deliver
```

For an ad, a demo, a social series, a brand board with motion.

1. Brief: purpose, audience, placements, aspect ratios, total length, sound. One line each.
2. `copy`: script, on-screen text, captions. Nothing generated until the words are final.
3. `imagegen`: write the bible, lock the count, generate the style frame and every character or product reference. Then the stills the placements need.
4. `videogen`: shot list from the script, one clip per row, each started from a still where continuity matters. Assemble. Audio in three passes.
5. `review`: watch once straight through. Palette drift, morphing, drifting text, duplicate frames. Regenerate, do not patch in post.
6. Deliver with the bible and the shot list at the top so the set can be extended.

`blender` slots in at step 3 when a product or scene needs a render instead of a generated still.
